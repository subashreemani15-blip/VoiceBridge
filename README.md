VoiceBridge – Your Voice. Your Language. Your Rights.

About the Project

VoiceBridge is a bilingual voice-enabled assistant designed to make information about government schemes and public services more accessible to people in India.

It supports English and Tamil, allowing users to ask questions through text or voice and receive answers in their preferred language.

Key Features

- English and Tamil language support.
- Speech-to-text using Gnani AI.
- AI-powered question answering using Gemini.
- Text-to-speech using Gnani AI.
- Live microphone input.
- Audio file upload and transcription.

Technologies Used

- Python
- Flask
- HTML, CSS and JavaScript
- Gnani AI Speech-to-Text
- Gnani AI Text-to-Speech
- Google Gemini API

How to Run

1. Install the required packages:
   "pip install -r requirements.txt"

2. Create a ".env" file and add your API credentials:
   
   - GNANI_API_KEY_ID
   - GEMINI_API_KEY

3. Start the application:
   "python app.py"

4. Open "http://127.0.0.1:5000" in your browser.

Important Note

AI-generated information should be verified through official government sources. VoiceBridge does not make final eligibility decisions.
